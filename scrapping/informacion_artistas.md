8. Un hallazgo que creo que puede ser útil para tu proyecto

Hay una diferencia fuerte entre dos polos dentro del conjunto:

Polo material

Mohaded → Mena → Lovrovich → Ferro → Fasoli → Sensi

La pregunta parece ser:

¿Qué puede hacer una materia cuando se la fuerza, transforma, desgasta, imprime, quema, cose, ilumina o combina?

Polo territorial

Díaz → Rossetti → Luna Sudaca → Fernández → Fasoli → Mena

La pregunta se desplaza hacia:

¿Cómo una geografía termina incorporándose al cuerpo, la memoria y la producción de imágenes?

Y hay un tercer eje que cruza ambos:

Polo tecnológico / mediático

Rossetti → Chebo → Arrastoa → Mena → Lovrovich

donde aparecen:

software, MIDI, animación, video, VFX, fotografía, edición, archivo digital, reproducción, diseño.

Esto es particularmente interesante para la pregunta que ustedes planteaban en el proyecto de VAPOR / software para artistas: la plataforma no reúne únicamente disciplinas artísticas; reúne también distintas formas de producción, circulación, mediación y organización del arte.

Bibliografía / fuentes principales

Además de VAPOR, las fuentes que resultaron particularmente útiles fueron Fundación Konex, Museo Moderno de Buenos Aires, Universidad Nacional de Córdoba, Universidad Torcuato Di Tella, UNLP/Centro de Arte, Fondo Nacional de las Artes, Museo/Castagnino+macro, Culzi, CRUDO, Diderot, MUNAR, AMMAC, Cine.Ar, Valerie's Factory, y los sitios personales de los propios artistas. Por ejemplo, los CV completos de Mena, Mohaded, Rossetti y otros permiten contrastar datos que no aparecen en VAPOR.

Importante: para Ailén Alcaraz, Belén Ghiso, Juan Jesús Conde, Mauricio Chiappini y Mora Martínez Broder encontré evidencia parcial pero no suficiente para construir una biografía extensa con el mismo grado de confianza que para Mena, Rossetti, Fasoli, etc. No rellené esos huecos con información de homónimos.

Si el objetivo es usar esto como base de datos de VAPOR, el siguiente paso útil sería convertirlo en una matriz de los 24 × ~30 categorías, con valores normalizados (por ejemplo pintura, dibujo, fotografía, performance, Córdoba, Buenos Aires, UNC, residencia, cuerpo, territorio, etc.) y marcar cada dato como confirmado / inferido / no encontrado, además de conservar la fuente de cada celda. Eso permitiría después detectar automáticamente los clusters y categorías compartidas entre los artistas.
